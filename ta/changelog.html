பதிப்பு வரலாறு

எல்லை முக்கியத்துவம் வாய்ந்த பதிப்பு முனைகள் மட்டுமே தக்கவைக்கப்படுகின்றன. இடைப்பட்ட patch பதிப்புகளின் முழு வேறுபாட்டையும் GitHub இல் உள்ள commit வரலாறு மற்றும் Tagகளில் காணலாம்.

V3.0.1 நிலையான பதிப்பு

  • உண்மையான திட்டங்களில் digraph கையாளல் சரிசெய்யப்பட்டது: GCC -E இன் <: எழுத்துவடிவம் பாதுகாக்கப்பட்டு, <:: வெளியீட்டு இடைவெளி சரியாகக் கையாளப்படுகிறது.
  • உண்மையான திட்ட corpus இப்போது முன்செயலாக்கமும் தொகுப்பும் உண்மையிலேயே வெற்றி பெற வேண்டும் எனக் கோருகிறது; “இரு பக்கமும் தோல்வியடைந்தது” என்பதை இனி தேர்ச்சியாகத் தவறாகக் கருதாது.
  • nlohmann/json இன் include அமைப்பு பின்வருமாறு சரிசெய்யப்பட்டது: nlohmann/json.hpp.
  • புதிதாக clone செய்து, build செய்து, மூன்று GCC சோதனைத் தொகுப்புகளும் உண்மையான திட்டச் சரிபார்ப்பும் தேர்ச்சி பெற்றுள்ளன.
2026-11-17

V3.0.0 உரிம எல்லை

  • V3.0.0 மற்றும் அதற்குப் பின் வரும் பதிப்புகள் CC BY-NC 4.0 உரிமைக்கு மாறுகின்றன; V2.9.0 மற்றும் அதற்கு முன் வரும் பதிப்புகள் தொடர்ந்து MIT உரிமையைப் பயன்படுத்துகின்றன.
  • GCC13/14/15க்கான முழுமையான PCH ஆதரவு: பதிப்பு வரம்பு நீக்கப்பட்டு, GCC13/14 PCH magic சரிபார்ப்பு சரிசெய்யப்பட்டது.
  • PCH cache manifest தொகுப்பியின் பாதை, பதிப்பு, இயக்கக்கூடிய கோப்பின் hash மற்றும் option hash ஆகியவற்றைப் பதிவு செய்கிறது.
  • மூன்று CTest தொகுப்புகளும் 65/65ஐ எட்டுகின்றன.
2026-11-17

V2.9.0 GCC13/14

  • GCC 13.3 / 14.3க்கான C++11/14/17/20 profileகள் சேர்க்கப்பட்டன.
  • GCC13/14 இன் முழுமையான __has_* தகவல் சேர்க்கப்பட்டது.
  • சேர்க்கப்பட்டது: --gcc-version=13|14|15, --gcc <path> மற்றும் PATH தானியங்கிக் கண்டறிதல்.
  • மூன்று CTest தொகுப்புகளுக்கான இலக்குத் தேர்வு மற்றும் மூன்று தொகுப்பிகளுக்கான smoke matrix.

V2.7.0 அம்ச மைல்கல்

  • GCC 15.2 இன் #embed: பைனரி உட்பொதித்தல், limit, gnu::offset, prefix, suffix, if_empty.
  • செயல்படுத்தப்பட்டது: __has_embed, 0/1/2 ஐத் திருப்பித் தரும்.
  • முழுமையான UCN அடையாளங்காட்டி ஆதரவு: இணைத்தல், செல்லுபடித்தன்மைச் சரிபார்ப்பு, இயல்பாக்கப்பட்ட வெளியீடு, மற்றும் #/## எழுத்துவடிவம் பாதுகாக்கப்படுகிறது.
  • C++11 / C++14 / C++17 / C++20 profile.
  • differential சோதனை முறைமை, GCC g++.dg/cpp testsuite உடன் ஒருங்கிணைக்கப்பட்டது.
