முன்செயலாக்கத்தை நிர்ணயமாக்குங்கள்

CrucibleCpp ஒரு தனித்துவமான C++ முன்செயலி. இது நிலைகள் 1–4 ஐ இயக்கி, இலக்கு GCC நேரடியாக தொகுக்கக்கூடிய .i ஐ உருவாக்குகிறது.

# target GCC profile + headers

இணக்கம்

தெளிவான GCC பதிப்பு

--gcc-version அல்லது --gcc மூலம் தேர்ந்தெடுக்கவும்.

GCC பாணி கண்டறிதல்

Caret, include trace, warning ID மற்றும் -Werror.

உண்மையான திட்டங்கள்

nlohmann/json, fmt, spdlog GCC 13/14/15 உடன்.

இலக்குநிலை
GCC 15.2முழுமை
GCC 14.3முழுமை
GCC 13.3முழுமை
Windows x64 / UCRT64ஆதரவு
Linux / MSVC / Clangஆதரவு இல்லை
ஆவணங்கள்

விரைவு தொடக்கம்

இலக்கு GCC ஐ PATH இல் வைத்து g++ -E ஐ மாற்றவும்.

cruciblecpp-preprocessor.exe -P ` -std=c++20 src\main.cpp -o build\main.i g++ -std=c++20 build\main.i -o build\main.exe
