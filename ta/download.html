01

கணினி தேவைகள்

Windows x64. இலக்கு தொகுப்பி MinGW-w64 UCRT64 GCC 13.3 / 14.3 / 15.2. கூடுதல் runtime தேவையில்லை.

02

பயன்படுத்தும் முறை

பிரித்தெடுத்த பிறகு நேரடியாக இயக்கலாம். --gcc-version அல்லது --gcc மூலம் இலக்கு தொகுப்பியைத் தேர்ந்தெடுத்து, வெளியிடப்படும் .i கோப்பை அதே GCC மூலம் தொகுக்கவும்.

03

உரிமம்

V3.0.0 மற்றும் அதற்குப் பின் CC BY-NC 4.0; பெயர் குறிப்பிடலுடன் வணிகம் அல்லாத பயன்பாட்டை அனுமதிக்கிறது. வணிகப் பயன்பாட்டுக்குத் தனி அனுமதி தேவை.

Before you run

இலக்கு GCC PATHஇல் உள்ளதை முதலில் உறுதிசெய்யுங்கள்

CrucibleCpp இலக்கு தொகுப்பியின் profile மற்றும் include பாதைகளைத் தானாகவே படிக்கும். தனிப்பயன் அடைவில் நிறுவியிருந்தால், --gcc மூலம் குறிப்பிட்டு, பதிப்புக் கலப்பைத் தவிர்க்கவும்.

cruciblecpp-preprocessor.exe --version cruciblecpp-preprocessor.exe --gcc "D:\path\to\g++.exe" -P src\main.cpp -o build\main.i
நிறுவல் மற்றும் கட்டளை வரி ஆவணங்களைப் படிக்க
