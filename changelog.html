Changelog

版本记录

只保留有边界意义的版本节点。中间补丁版的完整差异可在 GitHub 的提交历史和 Tag 中查看。

2026-11-26 · latest

V3.1.0 稳定版

  • Windows GUI 成为正式组件：和 CLI 共用同一套 cpp_preproc 核心，不使用 Qt / WebView2 / Electron。
  • GUI 支持显式选择源文件/输出、GCC 检测、C++11/14/17/20、后台预处理与取消。
  • GUI 支持 Include/宏/PCH/行标记/注释选项、g++ -E 对比、把 .i 编译为 .exe。
  • GUI 增加悬停动画、拖放、设置持久化、CLI 命令复制和全窗口自适应输出/诊断布局。
  • 修复只读输出控件滚动重影、标准下拉框与“预处理”按钮重叠、高 DPI 信息区未铺满窗口。
  • CLI 版本同步为 3.1.0；许可证仍为 CC BY-NC 4.0。
2026-11-17

V3.0.1 稳定版

  • 修复真实项目中的 digraph 处理：保留 GCC -E 的 <: 拼写，并正确处理 <:: 的输出间距。
  • 真实项目 corpus 现在要求预处理和编译真正成功，不再把“两边都失败”误判为通过。
  • 修正 nlohmann/json 的 include 布局为 nlohmann/json.hpp。
  • 从零 clone、构建、三套 GCC 测试与真实项目验证通过。
2026-11-17

V3.0.0 许可证边界

  • V3.0.0 及以后切换为 CC BY-NC 4.0；V2.9.0 及以前继续使用 MIT。
  • 完整 PCH 支持 GCC13/14/15：移除版本限制，修复 GCC13/14 PCH magic 校验。
  • PCH cache manifest 记录编译器路径、版本、可执行文件哈希和选项 hash。
  • 三套 CTest 均达到 65/65。
2026-11-17

V2.9.0 GCC13/14

  • 增加 GCC 13.3 / 14.3 的 C++11/14/17/20 profile。
  • 增加 GCC13/14 的完整 __has_* 数据。
  • 增加 --gcc-version=13|14|15、--gcc <path> 和 PATH 自动检测。
  • 三套 CTest 目标选择和三编译器 smoke matrix。
2026-11-14

V2.7.0 功能里程碑

  • 实现 GCC 15.2 的 #embed：二进制嵌入、limit、gnu::offset、prefix、suffix、if_empty。
  • 实现 __has_embed，返回 0/1/2。
  • 完整 UCN 标识符支持：组合、合法性检查、规范化输出、#/## 拼写保留。
  • C++11 / C++14 / C++17 / C++20 profile。
  • 差分测试系统与 GCC g++.dg/cpp testsuite 接入。
2026-11-12

V2.6.1 诊断升级

  • GCC 风格源码行、caret、include trace。
  • #error/#warning 前缀、宏重定义 warning、缺失 include fatal。
  • -fdiagnostics-color、caret/option 开关。
  • #pragma GCC diagnostic 状态栈。
