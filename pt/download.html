01

Requisitos do sistema

Windows x64. O compilador de destino é MinGW-w64 UCRT64 GCC 13.3 / 14.3 / 15.2. Nenhum runtime adicional é necessário.

02

Como usar

Descompacte e execute diretamente. Use --gcc-version ou --gcc para selecionar o compilador de destino e gerar o .i para ser compilado pelo mesmo GCC.

03

Licença

V3.0.0 e posteriores usam CC BY-NC 4.0, que permite uso não comercial com atribuição. O uso comercial exige licença separada.

Before you run

Primeiro, confirme se o GCC de destino está no PATH

O CrucibleCpp lê automaticamente o perfil e os caminhos de include do compilador de destino. Se estiver instalado em um diretório personalizado, use --gcc para especificá-lo e evitar mistura de versões.

cruciblecpp-preprocessor.exe --version cruciblecpp-preprocessor.exe --gcc "D:\path\to\g++.exe" -P src\main.cpp -o build\main.i
