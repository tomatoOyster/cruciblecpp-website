在 VS Code 里
直接使用 CrucibleCpp

官方 VS Code 插件把 CrucibleCpp 接进编辑器：预处理当前文件、查看只读 .i、读取 Problems 诊断、保存结果，并和 g++ -E 做差分。

打开插件仓库 → 下载 VSIX

它解决什么问题

命令行预处理适合构建系统，但调试宏、include 和预处理诊断时，来回切终端很费劲。插件把同一套 CrucibleCpp 结果放进 VS Code：当前文件可以直接预处理，结果以只读方式打开，诊断进入 Problems。

它不是重新实现一套预处理逻辑，而是调用你配置的 cruciblecpp-preprocessor.exe，因此输出与命令行保持一致。

功能

  • 预处理当前文件，生成只读 .i 预览
  • 把预处理诊断送到 VS Code Problems
  • 保存预处理结果为 .i 文件
  • 与 g++ -E 的输出做 diff
  • 读取 compile_commands.json 获取编译参数
  • 查看 GCC include 路径
  • 宏展开动画和 include 图（需要 CrucibleCpp 2.2.0+）
  • PCH 策略设置（需要 CrucibleCpp 2.3.0+）

安装

从插件 Release 下载 .vsix，然后执行：

code --install-extension path\to\cruciblecpp-vscode.vsix

插件依赖本仓库构建的 cruciblecpp-preprocessor.exe。如果它不在工作区的 build 或 bin 目录中，请在 VS Code 设置里配置：

"cruciblecpp.executable": "D:\\path\\to\\cruciblecpp-preprocessor.exe"

适用场景

排查宏展开、确认 include 来源、检查 PCH 是否被忽略、比较 CrucibleCpp 与 g++ -E 的输出差异，或者只是想在编辑器里快速看清一个文件最终变成了什么。
