01

시스템 요구 사항

Windows x64. 타깃 컴파일러는 MinGW-w64 UCRT64 GCC 13.3 / 14.3 / 15.2입니다. 추가 런타임이 필요하지 않습니다.

02

사용 방법

압축을 풀고 바로 실행하세요. --gcc-version 또는 --gcc 옵션으로 대상 컴파일러를 선택하고, 출력된 .i 파일을 같은 GCC로 컴파일합니다.

03

라이선스

V3.0.0 이후는 CC BY-NC 4.0이며, 저작자 표시를 조건으로 비상업적 사용을 허용합니다. 상업적 사용에는 별도 허가가 필요합니다.

Before you run

먼저 타깃 GCC가 PATH에 있는지 확인

CrucibleCpp는 타깃 컴파일러의 프로필과 include 경로를 자동으로 읽습니다. 사용자 지정 디렉터리에 설치했다면 --gcc 옵션으로 지정해 버전이 섞이지 않게 하세요.

cruciblecpp-preprocessor.exe --version cruciblecpp-preprocessor.exe --gcc "D:\path\to\g++.exe" -P src\main.cpp -o build\main.i
