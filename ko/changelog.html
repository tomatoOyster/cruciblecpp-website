버전 기록

경계를 표시하는 버전 노드만 남깁니다. 중간 패치 버전의 전체 차이는 GitHub의 커밋 기록과 Tag에서 확인할 수 있습니다.

2026-11-17 · latest

V3.0.1 안정 버전

  • 실제 프로젝트의 digraph 처리 수정: GCC -E 의 <: 표기를 유지하고 <:: 의 출력 간격을 올바르게 처리합니다.
  • 실제 프로젝트 corpus는 이제 전처리와 컴파일이 실제로 성공할 것을 요구하며, “양쪽 모두 실패”를 통과로 잘못 판정하지 않습니다.
  • nlohmann/json의 include 레이아웃을 다음으로 수정: nlohmann/json.hpp.
  • 클린 clone, 빌드, 세 개의 GCC 테스트, 실제 프로젝트 검증까지 통과했습니다.
2026-11-17

V3.0.0 라이선스 경계

  • V3.0.0 이후에는 CC BY-NC 4.0으로 전환되고, V2.9.0 이전은 MIT를 계속 사용합니다.
  • GCC13/14/15 완전 PCH 지원: 버전 제한 제거, GCC13/14 PCH magic 검증 수정.
  • PCH cache manifest는 컴파일러 경로, 버전, 실행 파일 해시, 옵션 hash를 기록합니다.
  • 세 개의 CTest 스위트 모두 65/65를 달성했습니다.
2026-11-17

V2.9.0 GCC13/14

  • GCC 13.3 / 14.3용 C++11/14/17/20 profile 추가.
  • GCC13/14의 전체 __has_* 데이터 추가.
  • 추가: --gcc-version=13|14|15, --gcc <path> 및 PATH 자동 감지.
  • 세 개 CTest 스위트의 대상 선택과 3개 컴파일러 smoke matrix.
2026-11-14

V2.7.0 기능 마일스톤

  • GCC 15.2의 #embed 구현: 바이너리 임베드, limit, gnu::offset, prefix, suffix, if_empty.
  • 구현: __has_embed, 0/1/2 반환.
  • 완전한 UCN 식별자 지원: 결합, 유효성 검사, 정규화 출력, #/## 표기 유지.
  • C++11 / C++14 / C++17 / C++20 profile.
  • 차분 테스트 시스템과 GCC g++.dg/cpp testsuite 연동.
2026-11-12

V2.6.1 진단 개선

  • GCC 스타일 소스 줄, caret, include trace.
  • #error/#warning 접두사, 매크로 재정의 경고, include 누락은 치명적 오류로 처리.
  • -fdiagnostics-color, caret/option 스위치.
  • #pragma GCC diagnostic 상태 스택.
