Системные требования

Windows x64. Целевой компилятор — MinGW-w64 UCRT64 GCC 13.3 / 14.3 / 15.2. Дополнительная среда выполнения не требуется.

02

Как использовать

Распакуйте архив — и можно запускать. Используйте --gcc-version или --gcc для выбора целевого компилятора; полученный .i передайте тому же GCC для компиляции.

03

Лицензия

Начиная с V3.0.0 действует CC BY-NC 4.0: разрешено использование с указанием авторства в некоммерческих целях. Для коммерческого использования требуется отдельная лицензия.

Before you run

Сначала убедитесь, что целевой GCC находится в PATH

CrucibleCpp автоматически читает профиль целевого компилятора и пути include. Если компилятор установлен в нестандартном каталоге, используйте --gcc для явного указания — так вы избежите смешивания версий.

cruciblecpp-preprocessor.exe --version cruciblecpp-preprocessor.exe --gcc "D:\path\to\g++.exe" -P src\main.cpp -o build\main.i
