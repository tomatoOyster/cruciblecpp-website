Changelog

История версий

Сохраняются только версии, имеющие принципиальное значение. Полные различия промежуточных патч-версий можно посмотреть в истории коммитов и тегах на GitHub.

2026-11-17 · latest

V3.0.1 Стабильная

  • Исправить обработку digraph в реальных проектах: сохранить то, как GCC -E записывает <: и корректно обрабатывать интервалы <:: в выводе.
  • Корпус реальных проектов теперь требует, чтобы препроцессирование и компиляция действительно завершались успешно, а «оба провалились» больше не считается прохождением.
  • Исправить раскладку include для nlohmann/json на nlohmann/json.hpp.
  • Клонирование с нуля, сборка, три набора тестов GCC и проверка на реальных проектах — пройдены.
2026-11-17

V3.0.0 Граница лицензии

  • Начиная с V3.0.0 используется CC BY-NC 4.0; для V2.9.0 и более ранних — по-прежнему MIT.
  • Полная поддержка PCH в GCC13/14/15: снято ограничение по версии, исправлена проверка magic PCH в GCC13/14.
  • Манифест кэша PCH фиксирует путь к компилятору, версию, хеш исполняемого файла и хеш опций.
  • Все три набора CTest достигают 65/65.
2026-11-17

V2.9.0 GCC13/14

  • Добавлены профили C++11/14/17/20 для GCC 13.3 / 14.3.
  • Добавлены полные __has_* данные GCC13/14.
  • Добавлен --gcc-version=13|14|15, --gcc <path> и автоопределение в PATH.
  • Выбор целей для всех трёх наборов CTest и smoke matrix с тремя компиляторами.
2026-11-14

V2.7.0 Веха функциональности

  • В GCC 15.2 реализован #embed: бинарное встраивание, limit, gnu::offset, prefix, suffix, if_empty.
  • Реализован __has_embed, возвращающий 0/1/2.
  • Полная поддержка идентификаторов UCN: композиция, проверка допустимости, нормализованный вывод и #/## с сохранением написания.
  • C++11 / C++14 / C++17 / C++20 profile.
  • Дифференциальное тестирование интегрировано с GCC g++.dg/cpp testsuite.
2026-11-12

V2.6.1 Улучшение диагностики

  • Строка исходного кода в стиле GCC, caret и include trace.
  • #error/#warning префиксы, предупреждения о переопределении макросов и фатальные ошибки при отсутствии include.
  • -fdiagnostics-color, а также переключатели caret/option.
  • #pragma GCC diagnostic стек состояний.

Более ранние версии

Релизы v2.5.0, v2.2.0, v2.0.0, v1.0.2 и другие сохранены. Промежуточные патч-версии убраны со страницы Release, но Git Tag по-прежнему полностью сохранены в репозитории.
