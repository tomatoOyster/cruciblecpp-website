Changelog

版本記錄

只保留具分界意義的版本節點。中間修補版的完整差異可在 GitHub 的提交歷史與 Tag 中查看。

2026-11-17 · latest

V3.0.1 穩定版

  • 修正真實專案中的 digraph 處理：保留 GCC -E 的 <: 拼寫，並正確處理 <:: 的輸出間距。
  • 真實專案 corpus 現在要求預處理與編譯真正成功，不再把「兩邊都失敗」誤判為通過。
  • 修正 nlohmann/json 的 include 配置為 nlohmann/json.hpp。
  • 從零 clone、建置、三套 GCC 測試與真實專案驗證皆通過。
2026-11-17

V3.0.0 授權邊界

  • V3.0.0 及以後切換為 CC BY-NC 4.0；V2.9.0 及以前繼續使用 MIT。
  • 完整 PCH 支援 GCC13/14/15：移除版本限制，修正 GCC13/14 PCH magic 驗證。
  • PCH cache manifest 記錄編譯器路徑、版本、執行檔雜湊與選項雜湊。
  • 三套 CTest 均達到 65/65。
2026-11-17

V2.9.0 GCC13/14

  • 新增 GCC 13.3 / 14.3 的 C++11/14/17/20 profile。
  • 新增 GCC13/14 的完整 __has_* 資料。
  • 新增 --gcc-version=13|14|15、--gcc <path> 與 PATH 自動偵測。
  • 三套 CTest 目標選擇與三編譯器 smoke matrix。
2026-11-14

V2.7.0 功能里程碑

  • 實作 GCC 15.2 的 #embed：二進位嵌入、limit、gnu::offset、prefix、suffix、if_empty。
  • 實作 __has_embed，傳回 0/1/2。
  • 完整 UCN 識別字支援：組合、合法性檢查、正規化輸出、#/## 拼寫保留。
  • C++11 / C++14 / C++17 / C++20 profile。
  • 差分測試系統與 GCC g++.dg/cpp testsuite 整合。
2026-11-12

V2.6.1 診斷升級

  • GCC 風格的原始碼行、caret、include trace。
  • #error/#warning 前綴、巨集重新定義 warning、缺少 include 視為 fatal。
  • -fdiagnostics-color、caret/option 開關。
  • #pragma GCC diagnostic 狀態堆疊。

更早的版本

v2.5.0、v2.2.0、v2.0.0、v1.0.2 等 Release 仍保留。中間的修補版本已從 Release 頁面移除，但 Git Tag 仍完整保留在倉庫中。
