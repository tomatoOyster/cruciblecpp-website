01

系統需求

Windows x64。目標編譯器為 MinGW-w64 UCRT64 GCC 13.3 / 14.3 / 15.2。無需額外執行階段。

02

使用方式

解壓縮後直接執行。用 --gcc-version 或 --gcc 選擇目標編譯器，輸出 .i 交給同一個 GCC 編譯。

03

授權

V3.0.0 及以後為 CC BY-NC 4.0，允許署名、非商業使用。商業使用需另行授權。

Before you run

先確認目標 GCC 已在 PATH 中

CrucibleCpp 會自動讀取目標編譯器的 profile 和 include 路徑。若安裝在自訂目錄，用 --gcc 指定，避免版本混用。

cruciblecpp-preprocessor.exe --version cruciblecpp-preprocessor.exe --gcc "D:\path\to\g++.exe" -P src\main.cpp -o build\main.i
