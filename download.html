01

系统要求

Windows x64。目标编译器为 MinGW-w64 UCRT64 GCC 13.3 / 14.3 / 15.2。无需额外运行时。

02

使用方式

解压后直接运行。用 --gcc-version 或 --gcc 选择目标编译器，输出 .i 交给同一个 GCC 编译。

03

许可证

V3.0.0 及以后为 CC BY-NC 4.0，允许署名、非商业使用。商业使用需要单独授权。

Before you run

先确认目标 GCC 在 PATH 中

CrucibleCpp 会自动读取目标编译器的 profile 和 include 路径。若安装在自定义目录，用 --gcc 指定，避免版本混用。

cruciblecpp-preprocessor.exe --version cruciblecpp-preprocessor.exe --gcc "D:\path\to\g++.exe" -P src\main.cpp -o build\main.i
