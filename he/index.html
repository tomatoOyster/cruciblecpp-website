תאימות

גרסת GCC מפורשת

בחר עם --gcc-version או --gcc.

אבחון בסגנון GCC

Caret, include trace, warning ID ו--Werror.

פרויקטים אמיתיים

nlohmann/json, fmt ו-spdlog עם GCC 13/14/15.

התחלה מהירה
