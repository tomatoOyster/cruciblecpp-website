Unduh V3.0.1
WINDOWS X64 · GCC 13 / 14 / 15

Buat prapemrosesan menjadi deterministik

CrucibleCpp adalah prapemroses C++ mandiri. Ia menjalankan fase 1–4 dan menghasilkan .i yang dapat dikompilasi langsung oleh GCC target.

Mulai cepat

Letakkan GCC target di PATH dan ganti g++ -E.

cruciblecpp-preprocessor.exe -P ` -std=c++20 src\main.cpp -o build\main.i g++ -std=c++20 build\main.i -o build\main.exe
