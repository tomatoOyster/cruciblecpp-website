Unduh V3.0.1
Changelog

Riwayat versi

Yang dipertahankan hanya node versi yang menandai batas. Perbedaan lengkap versi patch di antaranya dapat dilihat di riwayat commit dan Tag di GitHub.

2026-11-17 · latest

V3.0.1 Stabil

  • Perbaiki penanganan digraph di proyek nyata: pertahankan cara GCC -E menulis <: dan tangani <:: spasi output dengan benar.
  • Corpus proyek nyata kini menuntut praproses dan kompilasi benar-benar berhasil, dan tidak lagi salah menganggap “kedua sisi gagal” sebagai lulus.
  • Perbaiki tata letak include nlohmann/json menjadi nlohmann/json.hpp.
  • Clone dari nol, build, tiga rangkaian tes GCC, dan verifikasi proyek nyata semuanya lulus.
2026-11-17

V3.0.0 Batas lisensi

  • V3.0.0 dan setelahnya beralih ke CC BY-NC 4.0; V2.9.0 dan sebelumnya tetap menggunakan MIT.
  • Dukungan PCH penuh untuk GCC13/14/15: hapus batasan versi, perbaiki validasi magic PCH GCC13/14.
  • Manifest cache PCH mencatat jalur compiler, versi, hash executable, dan hash opsi.
  • Ketiga rangkaian CTest mencapai 65/65.
2026-11-17

V2.9.0 GCC13/14

  • Tambahkan profil C++11/14/17/20 untuk GCC 13.3 / 14.3.
  • Tambahkan data lengkap __has_* untuk GCC13/14.
  • Tambahkan --gcc-version=13|14|15, --gcc <path> dan deteksi otomatis PATH.
  • Pemilihan target untuk ketiga rangkaian CTest dan smoke matrix tiga compiler.
2026-11-14

V2.7.0 Tonggak fitur

  • Implementasikan dukungan GCC 15.2 untuk #embed: penyematan biner, limit, gnu::offset, prefix, suffix, if_empty.
  • Implementasikan __has_embedyang mengembalikan 0/1/2.
  • Dukungan penuh identifier UCN: komposisi, pemeriksaan validitas, output ternormalisasi, serta ejaan#/## tetap dipertahankan.
  • C++11 / C++14 / C++17 / C++20 profile.
  • Sistem pengujian diferensial yang terhubung ke testsuite g++.dg/cpp milik GCC.
2026-11-12

V2.6.1 Peningkatan diagnostik

  • Baris sumber bergaya GCC, caret, dan include trace.
  • #error/#warning sebagai awalan, peringatan redefinisi makro, dan include yang hilang dianggap fatal.
  • -fdiagnostics-color, serta sakelar caret/option.
  • #pragma GCC diagnostic menyediakan tumpukan status.

Versi lebih lama

Rilis seperti v2.5.0, v2.2.0, v2.0.0, dan v1.0.2 tetap dipertahankan. Versi patch di antaranya telah dihapus dari halaman Release, tetapi Git Tag tetap tersimpan lengkap di repositori.
