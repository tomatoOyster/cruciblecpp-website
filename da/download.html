Systemkrav

Windows x64. Målkompileren er MinGW-w64 UCRT64 GCC 13.3 / 14.3 / 15.2. Der kræves ingen ekstra runtime.

02

Sådan bruges den

Kør den direkte efter udpakning. Brug --gcc-version eller --gcc Vælg målkompileren, og output .i og kompilér med samme GCC.

03

Licens

V3.0.0 og senere er CC BY-NC 4.0, der tillader ikke-kommerciel brug med navngivelse. Kommerciel brug kræver en særskilt licens.

Before you run

Kontrollér først, at mål-GCC'en er i PATH

CrucibleCpp læser automatisk målkompilerens profil og include-stier. Hvis den er installeret i en brugerdefineret mappe, brug --gcc angiver, så versionsblanding undgås.

cruciblecpp-preprocessor.exe --version cruciblecpp-preprocessor.exe --gcc "D:\path\to\g++.exe" -P src\main.cpp -o build\main.i
