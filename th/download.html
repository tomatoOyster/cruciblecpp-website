01

ข้อกำหนดของระบบ

Windows x64 คอมไพเลอร์เป้าหมายคือ MinGW-w64 UCRT64 GCC 13.3 / 14.3 / 15.2 ไม่ต้องใช้รันไทม์เพิ่มเติม

02

วิธีใช้งาน

แตกไฟล์แล้วรันได้ทันที ใช้ --gcc-version หรือ --gcc เพื่อเลือกคอมไพเลอร์เป้าหมายและส่งออก .i แล้วส่งให้ GCC ตัวเดียวกันคอมไพล์

03

ใบอนุญาต

V3.0.0 เป็นต้นไปใช้ CC BY-NC 4.0 ซึ่งอนุญาตให้ใช้โดยระบุที่มาและไม่ใช่เชิงพาณิชย์ การใช้เชิงพาณิชย์ต้องได้รับอนุญาตแยกต่างหาก

Before you run

ตรวจสอบก่อนว่า GCC เป้าหมายอยู่ใน PATH

CrucibleCpp จะอ่านโปรไฟล์และเส้นทาง include ของคอมไพเลอร์เป้าหมายโดยอัตโนมัติ ถ้าติดตั้งไว้ในไดเรกทอรีที่กำหนดเอง ให้ใช้ --gcc เพื่อระบุ และหลีกเลี่ยงการปนกันของเวอร์ชัน

cruciblecpp-preprocessor.exe --version cruciblecpp-preprocessor.exe --gcc "D:\path\to\g++.exe" -P src\main.cpp -o build\main.i
