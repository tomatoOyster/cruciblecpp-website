WHY CRUCIBLECPP

ความเข้ากันได้

ระบุเวอร์ชัน GCC

เลือกด้วย --gcc-version หรือ --gcc.

ไดแอกนอสติกแบบ GCC

Caret, include trace, warning ID และ -Werror.

โปรเจกต์จริง

nlohmann/json, fmt และ spdlog กับ GCC 13/14/15.

เป้าหมายสถานะ
GCC 15.2สมบูรณ์
GCC 14.3สมบูรณ์
GCC 13.3สมบูรณ์
Windows x64 / UCRT64รองรับ
Linux / MSVC / Clangไม่รองรับ
เอกสาร

เริ่มต้นเร็ว

วาง GCC เป้าหมายใน PATH แล้วแทนที่ g++ -E.

cruciblecpp-preprocessor.exe -P ` -std=c++20 src\main.cpp -o build\main.i g++ -std=c++20 build\main.i -o build\main.exe
