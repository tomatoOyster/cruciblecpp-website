ประวัติเวอร์ชัน

เก็บไว้เฉพาะจุดเวอร์ชันที่มีความหมายในเชิงขอบเขต ส่วนความแตกต่างแบบเต็มของเวอร์ชันแพตช์ที่อยู่ระหว่างกลางดูได้จากประวัติคอมมิตและ Tag บน GitHub

2026-11-17 · latest

V3.0.1 เวอร์ชันเสถียร

  • แก้การจัดการ digraph ในโปรเจกต์จริง: คงการสะกดแบบที่ GCC -E ใช้สำหรับ <: ไว้ และจัดการ <:: ให้เว้นวรรคในเอาต์พุตอย่างถูกต้อง
  • corpus ของโปรเจกต์จริงตอนนี้กำหนดให้การประมวลผลล่วงหน้าและการคอมไพล์ต้องสำเร็จจริง และไม่ถือว่า “ทั้งสองฝ่ายล้มเหลว” เป็นการผ่านอีกต่อไป
  • แก้เลย์เอาต์ include ของ nlohmann/json เป็น nlohmann/json.hpp.
  • โคลนตั้งแต่ศูนย์ บิลด์ ผ่านการทดสอบ GCC ทั้งสามชุด และผ่านการตรวจสอบกับโปรเจกต์จริง
2026-11-17

V3.0.0 เส้นแบ่งใบอนุญาต

  • ตั้งแต่ V3.0.0 เป็นต้นไปเปลี่ยนเป็น CC BY-NC 4.0 ส่วน V2.9.0 และก่อนหน้ายังคงใช้ MIT
  • รองรับ PCH อย่างสมบูรณ์สำหรับ GCC13/14/15: ลบข้อจำกัดด้านเวอร์ชัน และแก้การตรวจสอบ PCH magic ของ GCC13/14
  • PCH cache manifest บันทึกเส้นทางคอมไพเลอร์ เวอร์ชัน แฮชของไฟล์เรียกทำงาน และแฮชของออปชัน
  • CTest ทั้งสามชุดถึง 65/65 ทั้งหมด
2026-11-17

V2.9.0 GCC13/14

  • เพิ่มโปรไฟล์ C++11/14/17/20 สำหรับ GCC 13.3 / 14.3
  • เพิ่มข้อมูล __has_* ของ GCC13/14 อย่างสมบูรณ์
  • เพิ่ม --gcc-version=13|14|15, --gcc <path> และการตรวจจับ PATH อัตโนมัติ
  • การเลือกเป้าหมายของ CTest ทั้งสามชุดและ smoke matrix สามคอมไพเลอร์
2026-11-14

V2.7.0 หมุดหมายคุณสมบัติ

  • รองรับ #embed ของ GCC 15.2: การฝังไบนารี, limit, gnu::offset, prefix, suffix, if_empty.
  • รองรับ __has_embed โดยคืนค่า 0/1/2
  • รองรับตัวระบุ UCN อย่างสมบูรณ์: การประกอบ การตรวจสอบความถูกต้อง เอาต์พุตที่ปรับให้เป็นมาตรฐาน และคงการสะกดของ #/## ไว้
  • C++11 / C++14 / C++17 / C++20 profile.
  • ระบบทดสอบเชิงเปรียบต่างที่เชื่อมต่อกับ g++.dg/cpp testsuite ของ GCC
2026-11-12

V2.6.1 ยกระดับไดแอกนอสติก

  • บรรทัดซอร์สแบบ GCC, caret และ include trace
  • #error/#warning นำหน้าข้อความ, คำเตือนเมื่อมาโครถูกนิยามซ้ำ และ include ที่หายไปถือเป็น fatal
  • -fdiagnostics-color และสวิตช์ caret/option
  • #pragma GCC diagnostic สแต็กสถานะ
