01

متطلبات النظام

Windows x64. المترجم الهدف هو MinGW-w64 UCRT64 GCC 13.3 / 14.3 / 15.2. ولا حاجة إلى وقت تشغيل إضافي.

02

طريقة الاستخدام

فكّ الضغط وشغّل البرنامج مباشرة. استخدم --gcc-version أو --gcc لاختيار المترجم الهدف وإخراج ملف .i لتسليمه إلى GCC نفسه للتجميع.

03

الترخيص

الإصدار V3.0.0 وما بعده بموجب CC BY-NC 4.0، مع السماح بالاستخدام غير التجاري بشرط الإسناد. أما الاستخدام التجاري فيتطلب ترخيصًا منفصلًا.

Before you run

تأكد أولًا من وجود GCC الهدف في PATH

يقرأ CrucibleCpp تلقائيًا ملف profile الخاص بالمترجم الهدف ومسارات include. وإذا كان مثبتًا في دليل مخصص، فاستخدم --gcc لتحديده وتجنّب خلط الإصدارات.

cruciblecpp-preprocessor.exe --version cruciblecpp-preprocessor.exe --gcc "D:\path\to\g++.exe" -P src\main.cpp -o build\main.i
