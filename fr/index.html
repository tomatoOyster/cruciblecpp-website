Rendez le prétraitement déterministe

CrucibleCpp est un préprocesseur C++ autonome. Il exécute les phases 1–4 et produit un .i que le GCC cible peut compiler directement.

Documentation

Démarrage rapide

Placez le GCC cible dans PATH, puis remplacez g++ -E.

cruciblecpp-preprocessor.exe -P ` -std=c++20 src\main.cpp -o build\main.i g++ -std=c++20 build\main.i -o build\main.exe
