Faceți preprocesarea deterministă

CrucibleCpp este un preprocesor C++ autonom. Execută fazele 1–4 și produce .i pe care GCC țintă îl compilează direct.

PowerShell — cruciblecpp
# target GCC profile + headers
PS> .\cruciblecpp-preprocessor.exe --gcc-version=15 `
       -P src\main.cpp -o build\main.i

PS> g++ -std=c++20 build\main.i -o build\main.exe
