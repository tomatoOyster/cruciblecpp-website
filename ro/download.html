Cerințe de sistem

Windows x64. Compilatorul țintă este MinGW-w64 UCRT64 GCC 13.3 / 14.3 / 15.2. Nu necesită un runtime suplimentar.

02

Mod de utilizare

Dezarhivați și rulați direct. Folosiți --gcc-version sau --gcc pentru a selecta compilatorul țintă, iar fișierul .i este compilat cu același GCC.

03

Licență

V3.0.0 și ulterior: CC BY-NC 4.0, cu atribuire și uz necomercial. Utilizarea comercială necesită o licență separată.

Before you run

Verificați mai întâi că GCC țintă este în PATH

CrucibleCpp citește automat profilul și căile de include ale compilatorului țintă. Dacă este instalat într-un director personalizat, folosiți --gcc pentru a-l specifica și a evita amestecarea versiunilor.

cruciblecpp-preprocessor.exe --version cruciblecpp-preprocessor.exe --gcc "D:\path\to\g++.exe" -P src\main.cpp -o build\main.i
