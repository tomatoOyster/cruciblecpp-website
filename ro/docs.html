Instalare

Descărcați arhiva pentru Windows x64 și dezarhivați-o în orice director. CrucibleCpp este un program unic, cu link-editare statică, care nu necesită instalarea unui runtime.

cruciblecpp-preprocessor.exe --version # cruciblecpp-preprocessor 3.0.1
Ținta actuală de producție: Windows x64 + MinGW-w64 UCRT64. Alte platforme, ABI-uri și versiuni GCC nu sunt acceptate oficial.

Start rapid

Verificați mai întâi că în PATH se găsește g++.exe. Apoi înlocuiți direct comanda g++ -E:

# Preprocesare .\cruciblecpp-preprocessor.exe -P -std=c++20 src\main.cpp -o build\main.i # Compilare cu același GCC g++ -std=c++20 build\main.i -o build\main.exe

Dacă GCC țintă nu este în PATH, folosiți --gcc pentru a-l specifica explicit:

.\cruciblecpp-preprocessor.exe ` --gcc "D:\GCC1413\gcc14\bin\g++.exe" ` -P -std=c++20 src\main.cpp -o build\main.i

Alegerea GCC

CrucibleCpp folosește macrocomenzile predefinite ale GCC țintă, datele __has_* și căile de căutare include. Nu folosiți profilul GCC15 pentru a preprocesa antetele GCC14.

MetodăComportament
--gcc-version=13|14|15Caută în PATH cea mai recentă versiune acceptată din aceeași serie majoră
--gcc <g++.exe>Folosește direct compilatorul indicat și îi citește versiunea și căile de include
NespecificatScanează PATH și alege implicit cea mai recentă versiune acceptată (15 → 14 → 13)
Detectarea automată scanează doar PATH. Dacă ați instalat compilatorul în alt director, adăugați-l în PATH sau folosiți --gcc, fără să vă bazați pe o literă de disc fixă.

Profile standard acceptate:

-std=c++11 C++11 profile -std=c++14 C++14 profile -std=c++17 C++17 profile -std=c++20 C++20 profile

PCH

Comanda g++ -E din GCC nu folosește .gch; PCH este folosit doar la compilarea propriu-zisă. CrucibleCpp citește implicit sursa antetelor și, opțional, validează, înregistrează și păstrează în cache PCH-urile generate extern.

# Afișează un avertisment când se găsește un .gch --pch=warn # Semnalează eroare când se găsește un .gch --pch=error # Înregistrează în analysis JSON PCH-urile ignorate --pch=report

Activarea cache-ului PCH:

.\cruciblecpp-preprocessor.exe ` --pch-cache .cache\pch ` --pch-cache-stats .cache\pch\stats.json ` -P src\main.cpp -o build\main.i

Manifestul cache-ului înregistrează calea compilatorului, versiunea, hash-ul compilatorului și hash-ul opțiunilor. PCH-urile pentru GCC13/14/15 nu se potrivesc greșit între ele.

Diagnostice

Afișează implicit linia sursă și caretul în stil GCC. Le puteți dezactiva sau ajusta:

-fdiagnostics-color=auto|always|never -fno-diagnostics-show-caret -fno-diagnostics-show-option -Werror -Wno-error=name --max-errors 20

Acceptă #pragma GCC diagnostic push/pop/ignored/warning/error și #pragma GCC system_header. Antetele incluse cu -isystem suprimă implicit avertismentele obișnuite,-Wsystem-headers le poate afișa din nou.

Depanare

Antetele bibliotecii standard nu au fost găsite

Compilatorul țintă nu este în PATH. Folosiți --gcc pentru a-l specifica sau adăugați directorul bin în PATH. De asemenea, puteți folosi -isystem pentru a-l indica explicit.

Versiune GCC greșită

Folosiți --gcc-version=13|14|15 pentru a fixa versiunea majoră, sau folosiți --gcc pentru a indica un g++.exe. Nu amestecați profilul țintă cu antetele altei versiuni.

Cache-ul PCH raportează corrupt

PCH-ul nu corespunde compilatorului/opțiunilor curente sau fișierul este deteriorat. Ștergeți intrarea din cache și regenerați-l; alternativ, dezactivați complet cache-ul PCH și lăsați-l să citească sursa antetelor.

Rezultatul nu poate fi compilat de GCC

Verificați mai întâi că preprocesarea și compilarea folosesc aceeași versiune GCC și -std. Apoi compilați separat „.i generat de CrucibleCpp” pentru a verifica dacă problema provine din etapa de preprocesare.

CrucibleCpp este un preprocesor, nu un compilator. Nu se ocupă de generarea de cod, de optimizare, de link-editare sau de analiza formatului intern al PCH-urilor binare GCC.
