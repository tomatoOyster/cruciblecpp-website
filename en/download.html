01

System requirements

Windows x64. The target compiler is MinGW-w64 UCRT64 GCC 13.3 / 14.3 / 15.2. No additional runtime is required.

02

Usage

Unzip and run it directly. Use --gcc-version or --gcc to select the target compiler and output the .i to be compiled by the same GCC.

03

License

V3.0.0 and later use CC BY-NC 4.0, which permits attributed, non-commercial use. Commercial use requires a separate license.

Before you run

First, make sure the target GCC is on your PATH

CrucibleCpp automatically reads the target compiler's profile and include paths. If it is installed in a custom directory, use --gcc to specify it and avoid mixing versions.

cruciblecpp-preprocessor.exe --version cruciblecpp-preprocessor.exe --gcc "D:\path\to\g++.exe" -P src\main.cpp -o build\main.i
