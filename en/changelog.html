Changelog

Version history

Only version nodes with boundary significance are kept. The full diff for intermediate patch releases is available in the commit history and tags on GitHub.

2026-11-17 · latest

V3.0.1 Stable

  • Fix digraph handling in real projects: preserve the way GCC -E spells <: and correctly handle <:: output spacing.
  • The real-project corpus now requires preprocessing and compilation to really succeed, and no longer mistakes “both sides failed” for a pass.
  • Correct the nlohmann/json include layout to nlohmann/json.hpp.
  • From-scratch clone, build, all three GCC test suites, and real-project verification pass.
2026-11-17

V3.0.0 License boundary

  • V3.0.0 and later switch to CC BY-NC 4.0; V2.9.0 and earlier continue to use MIT.
  • Full PCH support for GCC13/14/15: remove the version restriction and fix GCC13/14 PCH magic validation.
  • The PCH cache manifest records the compiler path, version, executable hash, and option hash.
  • All three CTest suites reach 65/65.
2026-11-17

V2.9.0 GCC13/14

  • Add C++11/14/17/20 profiles for GCC 13.3 / 14.3.
  • Add GCC13/14's full __has_* data.
  • Add --gcc-version=13|14|15, --gcc <path> and PATH auto-detection.
  • Target selection for all three CTest suites and a three-compiler smoke matrix.
2026-11-14

V2.7.0 Feature milestone

  • Implement GCC 15.2's #embed: binary embedding, limit, gnu::offset, prefix, suffix, if_empty.
  • Implement __has_embed, returning 0/1/2.
  • Full UCN identifier support: composition, validity checking, normalized output, and #/## spelling preserved.
  • C++11 / C++14 / C++17 / C++20 profile.
  • Differential testing system integrated with the GCC g++.dg/cpp testsuite.
2026-11-12

V2.6.1 Diagnostics upgrade

  • GCC-style source line, caret, and include trace.
  • #error/#warning prefixes, macro redefinition warnings, and missing includes as fatal errors.
  • -fdiagnostics-color, plus the caret/option switches.
  • #pragma GCC diagnostic state stack.

Earlier versions

Releases such as v2.5.0, v2.2.0, v2.0.0, and v1.0.2 are kept. Intermediate patch versions have been removed from the Releases page, but the Git tags are still fully preserved in the repository.
