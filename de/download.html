01

Systemanforderungen

Windows x64. Ziel-Compiler ist MinGW-w64 UCRT64 GCC 13.3 / 14.3 / 15.2. Keine zusätzliche Laufzeitumgebung erforderlich.

02

Verwendung

Nach dem Entpacken direkt ausführen. Wählen Sie mit --gcc-version oder --gcc den Ziel-Compiler; die erzeugte .i übergeben Sie demselben GCC zum Kompilieren.

03

Lizenz

Ab V3.0.0 gilt CC BY-NC 4.0: Namensnennung und nichtkommerzielle Nutzung sind erlaubt. Für kommerzielle Nutzung ist eine separate Lizenz erforderlich.

Before you run

Prüfen Sie zuerst, ob der Ziel-GCC im PATH liegt

CrucibleCpp liest das Profil und die Include-Pfade des Ziel-Compilers automatisch. Bei einer Installation in einem benutzerdefinierten Verzeichnis geben Sie ihn mit --gcc an, um Versionsmischungen zu vermeiden.

cruciblecpp-preprocessor.exe --version cruciblecpp-preprocessor.exe --gcc "D:\path\to\g++.exe" -P src\main.cpp -o build\main.i
