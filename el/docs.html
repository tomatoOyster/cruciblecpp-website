Εγκατάσταση

Κατεβάστε το αρχείο ZIP για Windows x64 και αποσυμπιέστε το σε οποιονδήποτε κατάλογο. Το CrucibleCpp είναι ένα στατικά συνδεδεμένο πρόγραμμα μεμονωμένου αρχείου και δεν απαιτεί εγκατάσταση runtime.

cruciblecpp-preprocessor.exe --version # cruciblecpp-preprocessor 3.0.1
Τρέχων στόχος παραγωγής: Windows x64 + MinGW-w64 UCRT64. Άλλες πλατφόρμες, ABI και εκδόσεις GCC δεν υποστηρίζονται εγγυημένα.

Γρήγορη εκκίνηση

Βεβαιωθείτε πρώτα ότι το PATH περιέχει το g++.exe. Στη συνέχεια, αντικαταστήστε απευθείας το g++ -E:

# Προεπεξεργασία .\cruciblecpp-preprocessor.exe -P -std=c++20 src\main.cpp -o build\main.i # Μεταγλώττιση με το ίδιο GCC g++ -std=c++20 build\main.i -o build\main.exe

Αν δεν έχετε προσθέσει τον GCC-στόχο στο PATH, χρησιμοποιήστε --gcc για να το καθορίσετε ρητά:

.\cruciblecpp-preprocessor.exe ` --gcc "D:\GCC1413\gcc14\bin\g++.exe" ` -P -std=c++20 src\main.cpp -o build\main.i

Επιλογή GCC

Το CrucibleCpp χρησιμοποιεί τις προκαθορισμένες μακροεντολές του GCC-στόχου, τα __has_* δεδομένα και τις διαδρομές αναζήτησης include. Μην χρησιμοποιείτε το profile του GCC15 για να προεπεξεργαστείτε headers του GCC14.

ΤρόποςΣυμπεριφορά
--gcc-version=13|14|15Αναζήτηση στο PATH της υψηλότερης υποστηριζόμενης έκδοσης που ταιριάζει με την κύρια έκδοση
--gcc <g++.exe>Χρήση απευθείας του καθορισμένου μεταγλωττιστή και ανάγνωση της έκδοσης και των διαδρομών include
Χωρίς προσδιορισμόΣάρωση του PATH, προεπιλογή της υψηλότερης υποστηριζόμενης έκδοσης (15 → 14 → 13)
Η αυτόματη ανίχνευση σαρώνει μόνο το PATH. Αν ο μεταγλωττιστής είναι εγκατεστημένος σε άλλον κατάλογο, προσθέστε τον στο PATH ή χρησιμοποιήστε --gcc, χωρίς να βασίζεστε σε σταθερό γράμμα δίσκου.

Υποστηριζόμενα standard profiles:

-std=c++11 C++11 profile -std=c++14 C++14 profile -std=c++17 C++17 profile -std=c++20 C++20 profile

PCH

Το g++ -E του GCC δεν χρησιμοποιεί .gch· τα PCH χρησιμοποιούνται μόνο κατά την πραγματική μεταγλώττιση. Το CrucibleCpp διαβάζει από προεπιλογή τον πηγαίο κώδικα των headers και προαιρετικά επικυρώνει, καταγράφει και αποθηκεύει σε cache εξωτερικά παραγόμενα PCH.

# Εμφάνιση warning όταν εντοπίζεται .gch --pch=warn # Άμεσο σφάλμα όταν εντοπίζεται .gch --pch=error # Καταγραφή των αγνοημένων PCH στο analysis JSON --pch=report

Ενεργοποίηση cache PCH:

.\cruciblecpp-preprocessor.exe ` --pch-cache .cache\pch ` --pch-cache-stats .cache\pch\stats.json ` -P src\main.cpp -o build\main.i

Το manifest της cache καταγράφει τη διαδρομή του μεταγλωττιστή, την έκδοση, το hash του μεταγλωττιστή και το hash των επιλογών. Τα PCH των GCC13/14/15 δεν συγκρούονται μεταξύ τους.

Διαγνωστικά

Από προεπιλογή παράγονται γραμμές πηγαίου κώδικα και caret σε στυλ GCC. Μπορούν να απενεργοποιηθούν ή να ρυθμιστούν:

-fdiagnostics-color=auto|always|never -fno-diagnostics-show-caret -fno-diagnostics-show-option -Werror -Wno-error=name --max-errors 20

Υποστηρίζει #pragma GCC diagnostic push/pop/ignored/warning/error και #pragma GCC system_header. Τα headers που προέρχονται από -isystem καταστέλλουν εξ ορισμού τις συνήθεις προειδοποιήσεις, -Wsystem-headers τις εμφανίζει ξανά.

Αντιμετώπιση προβλημάτων

Δεν βρίσκονται headers της standard library

Ο μεταγλωττιστής-στόχος δεν βρίσκεται στο PATH. Χρησιμοποιήστε --gcc για να τον καθορίσετε, ή προσθέστε τον κατάλογο bin στο PATH. Μπορείτε επίσης να χρησιμοποιήσετε -isystem για να το περάσετε ρητά.

Επιλέχθηκε λάθος έκδοση GCC

Χρησιμοποιήστε --gcc-version=13|14|15 για να καθορίσετε την κύρια έκδοση, ή --gcc για να δείξετε ένα συγκεκριμένο g++.exe. Μην αναμειγνύετε το target profile με headers άλλης έκδοσης.

Η cache PCH αναφέρει corrupt

Το PCH δεν ταιριάζει με τον τρέχοντα μεταγλωττιστή/τις επιλογές ή το αρχείο είναι κατεστραμμένο. Διαγράψτε την αντίστοιχη καταχώριση cache και δημιουργήστε το ξανά· μπορείτε επίσης να απενεργοποιήσετε την cache PCH ώστε να διαβάζει τον πηγαίο κώδικα των headers.

Η έξοδος δεν μεταγλωττίζεται από το GCC

Βεβαιωθείτε πρώτα ότι η προεπεξεργασία και η μεταγλώττιση χρησιμοποιούν την ίδια έκδοση GCC και την ίδια επιλογή -std. Στη συνέχεια, μεταγλωττίστε χωριστά το «.i που παράγει το CrucibleCpp» για να επιβεβαιώσετε αν το πρόβλημα προέρχεται από το στάδιο προεπεξεργασίας.

Το CrucibleCpp είναι προεπεξεργαστής, όχι μεταγλωττιστής. Δεν ασχολείται με παραγωγή κώδικα, βελτιστοποίηση, σύνδεση και ανάλυση της εσωτερικής μορφής των δυαδικών PCH του GCC.
