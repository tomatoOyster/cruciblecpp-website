Κάντε την προεπεξεργασία ντετερμινιστική

Το CrucibleCpp είναι αυτόνομος προεπεξεργαστής C++. Εκτελεί τις φάσεις 1–4 και παράγει .i που ο GCC προορισμού μεταγλωττίζει απευθείας.

Συμβατότητα

Ρητή έκδοση GCC

Επιλέξτε με --gcc-version ή --gcc.

Διαγνωστικά GCC

Caret, include trace, warning ID και -Werror.

Πραγματικά έργα

nlohmann/json, fmt και spdlog με GCC 13/14/15.

Τεκμηρίωση

Γρήγορη εκκίνηση

Βάλτε τον GCC προορισμού στο PATH και αντικαταστήστε το g++ -E.

cruciblecpp-preprocessor.exe -P ` -std=c++20 src\main.cpp -o build\main.i g++ -std=c++20 build\main.i -o build\main.exe
