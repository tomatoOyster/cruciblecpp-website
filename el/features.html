Λήψη V3.0.1
Capabilities

Χτίστε κάθε επίπεδο
με επαληθεύσιμη συμπεριφορά

Από την επιλογή έκδοσης-στόχου και τις προκαθορισμένες μακροεντολές έως τα διαγνωστικά, τα PCH και τα πραγματικά έργα, το CrucibleCpp δεν βασίζεται στο «θα έπρεπε να δουλέψει», αλλά σε μια αναπαραγώγιμη αλυσίδα δοκιμών.

A

Έκδοση-στόχος και profile

Ένας προεπεξεργαστής, τρεις GCC-στόχοι. Η έκδοση που επιλέγετε καθορίζει τις προκαθορισμένες μακροεντολές της και τα __has_* δεδομένα και τις διαδρομές αναζήτησης include.

  • --gcc-version=13|14|15
  • --gcc D:\path\to\g++.exe
  • Αυτόματη ανίχνευση στο PATH, προεπιλογή της υψηλότερης υποστηριζόμενης έκδοσης
  • GCC 13.3 / 14.3 / 15.2 profile
  • C++11 / C++14 / C++17 / C++20
B

Σύστημα διαγνωστικών

Μορφή διαγνωστικών για πραγματικά συστήματα build. Περιλαμβάνει γραμμή πηγαίου κώδικα, caret, include trace και warning option, όχι απλώς ένα αλφαριθμητικό σφάλματος.

  • severity / option / caret σε στυλ GCC
  • -Werror, -Wno-..., -Werror=...
  • #pragma GCC diagnostic push/pop
  • #pragma GCC system_header
  • -Wsystem-headers και καταστολή headers συστήματος
C

Μακροεντολές και σημασιολογία προεπεξεργασίας

Μακροεντολές αντικειμένου, μακροεντολές συνάρτησης, κενά ορίσματα, variadic μακροεντολές, stringification, token pasting και η επέκταση του GCC για αφαίρεση κόμματος.

  • # και ##
  • __VA_OPT__(C++20)
  • , ## __VA_ARGS__
  • defined / __has_include
  • Ανάλυση JSON macro trace και γράφου include
D

UCN και #embed

Τα universal character names συμμετέχουν σε αναγνωριστικά και σε συνένωση· #embed ενσωματώνει δυαδικούς πόρους σύμφωνα με τη σημασιολογία του GCC.

  • \uXXXX / \UXXXXXXXX
  • UCN που σχηματίζονται από backslash στο τέλος γραμμής
  • # / ## διατηρούν τη γραφή UCN
  • #embed + limit
  • prefix / suffix / if_empty
  • gnu::offset και __has_embed
E

PCH και cache

Και τα τρία GCC 13/14/15 μπορούν να χρησιμοποιήσουν πολιτικές PCH και cache. Η cache δεν αναλύει απευθείας τα PCH του GCC, αλλά επικυρώνει, καταγράφει, ακυρώνει και παρακολουθεί τα εξωτερικά αρχεία .gch.

  • --pch=ignore|warn|error|report
  • Διάταξη PCH του CMake με αναγκαστικό include
  • Απομόνωση διαδρομής, έκδοσης και hash μεταγλωττιστή
  • Ατομική εγγραφή, κλείδωμα καταλόγου, καθαρισμός με βάση τη χωρητικότητα και την ηλικία
  • Στατιστικά JSON hit rate / stale / corrupt
F

Αναπαραγώγιμες δοκιμές

Τρία GCC, δύο differential corpora και πραγματικά έργα επαληθεύουν από κοινού την έξοδο, όχι μόνο την «επιτυχή προεπεξεργασία».

  • 65/65 CTest για GCC15 / 14 / 13
  • differential corpus 13/13
  • realworld corpus 3/3
  • CrucibleCpp .i → GCC-στόχος → exe → εκτέλεση
  • GCC g++.dg/cpp testsuite με ελέγχους παλινδρόμησης
Positioning

Αντικαθιστά το βήμα προεπεξεργασίας, όχι τον μεταγλωττιστή

Το CrucibleCpp δεν κάνει παραγωγή κώδικα, δεν βελτιστοποιεί και δεν αναλύει δυαδικά PCH του GCC. Αναλαμβάνει μόνο να μετατρέψει τα αρχεία πηγαίου κώδικα σε ένα καθορισμένο αρχείο .i, αναθέτοντας τα διαγνωστικά, τις εξαρτήσεις και τις αναλύσιμες πληροφορίες στο σύστημα build.
