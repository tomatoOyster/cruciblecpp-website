01

Systémové požadavky

Windows x64. Cílovým kompilátorem je MinGW-w64 UCRT64 GCC 13.3 / 14.3 / 15.2. Není potřeba žádné další běhové prostředí.

02

Způsob použití

Po rozbalení jej spusťte přímo. Pomocí --gcc-version nebo --gcc vyberte cílový kompilátor a výstup .i předejte ke kompilaci stejnému GCC.

Before you run

Nejprve ověřte, že cílový GCC je v PATH

CrucibleCpp automaticky načte profil a include cesty cílového kompilátoru. Pokud je nainstalován ve vlastním adresáři, použijte --gcc k jeho určení a vyhněte se míchání verzí.

cruciblecpp-preprocessor.exe --version cruciblecpp-preprocessor.exe --gcc "D:\path\to\g++.exe" -P src\main.cpp -o build\main.i
