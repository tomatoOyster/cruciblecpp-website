Why CrucibleCpp

No es otro expansor de macros,
sino una capa de preprocesado verificable

Todos los casos positivos pasan por la misma cadena: CrucibleCpp genera .i, que el GCC correspondiente compila en un exe y luego ejecuta de verdad. El comportamiento se mide tomando como referencia GCC 15.2, 14.3 y 13.3.

01

Versiones de destino explícitas

Usa --gcc-version o --gcc para seleccionar el compilador de destino. El perfil, las macros integradas y las rutas de include provienen del mismo destino y nunca se mezclan.

02

Paridad de diagnósticos con GCC

Caret del código fuente, include trace, warning ID, -Werror, la pila de pragma diagnostic y la supresión de advertencias en las cabeceras del sistema.

03

Validación con proyectos reales

nlohmann/json, fmt y spdlog se preprocesan, compilan y ejecutan con las tres versiones de GCC, cubriendo cabeceras reales y combinaciones de macros.

04

UCN completo

\uXXXX y \UXXXXXXXX participan en identificadores, #, ##; las comprobaciones de validez y la normalización de la salida se alinean con GCC.

05

#embed

Incrustación binaria, limit, gnu::offset, prefix, suffix, if_empty, así como __has_embed.

06

Aislamiento de versiones de PCH

Las estrategias de PCH y las cachés están disponibles para GCC 13 / 14 / 15. El manifest registra la ruta del compilador, su versión y el hash del ejecutable para evitar falsos aciertos entre versiones.

Compatibility

Empieza con una matriz explícita

El objetivo de producción actual está fijado en Windows x64 + MinGW-w64 UCRT64. Cada versión de GCC usa su propio perfil y sus propias cabeceras, y la salida se verifica compilándola realmente con el GCC correspondiente.

Test chain

La verificación no es “parece que funciona”

  • Tres suites de CTest para GCC15 / 14 / 13, con 65/65 en cada una
  • differential corpus 13/13: códigos de salida, diagnósticos y flujo de tokens
  • realworld corpus 3/3: nlohmann/json, fmt, spdlog
  • Cada caso positivo se ejecuta realmente después de generar el exe
  • La política y la caché de PCH se validan en las tres versiones
  • GCC g++.dg/cpp se ejecuta en regresión continua
