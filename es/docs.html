Instalación

Descargue el paquete comprimido de Windows x64 y descomprímalo en cualquier directorio. CrucibleCpp es un programa de archivo único enlazado estáticamente, por lo que no hay que instalar ningún runtime.

cruciblecpp-preprocessor.exe --version # cruciblecpp-preprocessor 3.0.1
Objetivo de producción actual: Windows x64 + MinGW-w64 UCRT64. No se garantiza la compatibilidad con otras plataformas, ABI y versiones de GCC.

Inicio rápido

Primero compruebe que PATH contiene el g++.exe. Después sustituya directamente su g++ -E:

# Preprocesar .\cruciblecpp-preprocessor.exe -P -std=c++20 src\main.cpp -o build\main.i # Compilar con el mismo GCC g++ -std=c++20 build\main.i -o build\main.exe

Si no ha añadido el GCC de destino a PATH, use --gcc para especificarlo explícitamente:

.\cruciblecpp-preprocessor.exe ` --gcc "D:\GCC1413\gcc14\bin\g++.exe" ` -P -std=c++20 src\main.cpp -o build\main.i

Seleccionar GCC

CrucibleCpp usa las macros predefinidas del GCC de destino, la información de __has_* y las rutas de búsqueda de include. No use un perfil de GCC 15 para preprocesar encabezados de GCC 14.

MétodoComportamiento
--gcc-version=13|14|15Busca en PATH el compilador admitido de versión más alta que coincida con la versión mayor
--gcc <g++.exe>Usa directamente el compilador indicado y lee su versión y sus rutas de include
Sin especificarExplora PATH y elige de forma predeterminada la versión admitida más alta (15 → 14 → 13)
La detección automática solo explora PATH. Si está instalado en otro directorio, añádalo a PATH, o use --gcc, y no dependa de una letra de unidad fija.

Perfiles estándar admitidos:

-std=c++11 C++11 profile -std=c++14 C++14 profile -std=c++17 C++17 profile -std=c++20 C++20 profile

PCH

El g++ -E de GCC no utiliza .gch; el PCH solo se usa durante la compilación real. De forma predeterminada, CrucibleCpp lee el código fuente de los encabezados y, opcionalmente, puede validar, registrar y almacenar en caché los PCH generados externamente.

# Avisar cuando se encuentre un .gch --pch=warn # Error inmediato al encontrar un .gch --pch=error # Registrar en el JSON de análisis los PCH ignorados --pch=report

Activar la caché de PCH:

.\cruciblecpp-preprocessor.exe ` --pch-cache .cache\pch ` --pch-cache-stats .cache\pch\stats.json ` -P src\main.cpp -o build\main.i

El manifest de la caché registra la ruta del compilador, la versión, el hash del compilador y el hash de las opciones. Los PCH de GCC 13/14/15 no se confunden entre sí.

Diagnósticos

De forma predeterminada, genera líneas de código fuente y caret al estilo de GCC. Puede desactivarlo o ajustarlo:

-fdiagnostics-color=auto|always|never -fno-diagnostics-show-caret -fno-diagnostics-show-option -Werror -Wno-error=name --max-errors 20

Admite #pragma GCC diagnostic push/pop/ignored/warning/error y #pragma GCC system_header. Los encabezados incluidos mediante -isystem suprimen las advertencias habituales de forma predeterminada, y -Wsystem-headers puede volver a mostrarlas.

Solución de problemas

No se encuentran los encabezados de la biblioteca estándar

El compilador de destino no está en PATH. Use --gcc para especificarlo, o añada el directorio bin a PATH. También puede usar -isystem para pasarlo explícitamente.

Se ha seleccionado una versión de GCC incorrecta

Use --gcc-version=13|14|15 para fijar la versión mayor, o use --gcc para apuntar al g++.exe. No mezcle un target profile con encabezados de otra versión.

La caché de PCH informa de «corrupt»

El PCH no coincide con el compilador ni con las opciones actuales, o el archivo está dañado. Elimine la entrada de caché correspondiente y vuelva a generarlo; también puede desactivar la caché de PCH y dejar que lea el código fuente de los encabezados.

La salida no se puede compilar con GCC

Primero asegúrese de que el preprocesado y la compilación usan la misma versión de GCC y -std. Después compile por separado el “.i” generado por CrucibleCpp para comprobar si el problema procede de la fase de preprocesado.

CrucibleCpp es un preprocesador, no un compilador. No se ocupa de la generación de código, la optimización, el enlazado ni del análisis del formato binario interno de los PCH de GCC.
