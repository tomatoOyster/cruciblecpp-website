01

Системні вимоги

Windows x64. Цільовий компілятор — MinGW-w64 UCRT64 GCC 13.3 / 14.3 / 15.2. Додаткове середовище виконання не потрібне.

02

Як використовувати

Розпакуйте й запускайте. Використовуйте --gcc-version або --gcc для вибору цільового компілятора; вивід .i передається на компіляцію тому самому GCC.

03

Ліцензія

V3.0.0 і новіші — CC BY-NC 4.0: дозволено некомерційне використання із зазначенням авторства. Комерційне використання потребує окремого дозволу.

Before you run

Спочатку переконайтеся, що цільовий GCC є в PATH

CrucibleCpp автоматично зчитує профіль цільового компілятора та шляхи include. Якщо компілятор встановлено в іншому каталозі, скористайтеся --gcc із зазначенням шляху, щоб уникнути змішування версій.

cruciblecpp-preprocessor.exe --version cruciblecpp-preprocessor.exe --gcc "D:\path\to\g++.exe" -P src\main.cpp -o build\main.i
