Зробіть препроцесинг детермінованим

CrucibleCpp — автономний препроцесор C++. Він виконує фази 1–4 і створює .i, який цільовий GCC компілює напряму.

# target GCC profile + headers

       -P src\main.cpp -o build\main.i

Сумісність

Явна версія GCC

Виберіть через --gcc-version або --gcc.

Діагностика GCC

Caret, include trace, warning ID і -Werror.

Реальні проєкти

nlohmann/json, fmt і spdlog з GCC 13/14/15.

Документація

Швидкий старт

Додайте цільовий GCC у PATH і замініть g++ -E.

cruciblecpp-preprocessor.exe -P ` -std=c++20 src\main.cpp -o build\main.i g++ -std=c++20 build\main.i -o build\main.exe
