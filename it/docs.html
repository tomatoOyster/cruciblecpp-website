Installazione

Scarica l'archivio Windows x64 e decomprimilo in una directory qualsiasi. CrucibleCpp è un programma in un unico file con linking statico: non serve installare alcun runtime.

cruciblecpp-preprocessor.exe --version # cruciblecpp-preprocessor 3.0.1
Target di produzione attuale: Windows x64 + MinGW-w64 UCRT64. Non è garantito il supporto per altre piattaforme, ABI e versioni di GCC.

Avvio rapido

Assicurati che nel PATH sia presente il g++.exe. Poi sostituisci direttamente il tuo g++ -E:

# Preprocessing .\cruciblecpp-preprocessor.exe -P -std=c++20 src\main.cpp -o build\main.i # Compila con lo stesso GCC g++ -std=c++20 build\main.i -o build\main.exe

Se il GCC target non è nel PATH, usa --gcc per specificarlo esplicitamente:

.\cruciblecpp-preprocessor.exe ` --gcc "D:\GCC1413\gcc14\bin\g++.exe" ` -P -std=c++20 src\main.cpp -o build\main.i

Scelta di GCC

CrucibleCpp usa le macro predefinite del GCC target, i dati di __has_* e i percorsi di ricerca degli include. Non usare un profilo GCC 15 per preprocessare gli header di GCC 14.

ModalitàComportamento
--gcc-version=13|14|15Cerca nel PATH il compilatore supportato più recente con la stessa versione principale
--gcc <g++.exe>Usa direttamente il compilatore indicato e ne legge la versione e i percorsi di include
Non specificatoAnalizza il PATH e sceglie per impostazione predefinita la versione supportata più alta (15 → 14 → 13)
Il rilevamento automatico analizza solo il PATH. Se è installato altrove, aggiungilo al PATH oppure usa --gcc, e non affidarti a una lettera di unità fissa.

Profili standard supportati:

-std=c++11 C++11 profile -std=c++14 C++14 profile -std=c++17 C++17 profile -std=c++20 C++20 profile

PCH

La modalità g++ -E di GCC non usa .gch; il PCH viene usato solo durante la compilazione reale. Per impostazione predefinita CrucibleCpp legge i sorgenti degli header e può, facoltativamente, convalidare, registrare e mettere in cache i PCH generati esternamente.

# Avvisa quando viene trovato un .gch --pch=warn # Errore immediato quando viene trovato un .gch --pch=error # Registra i PCH ignorati nell'analysis JSON --pch=report

Abilita la cache PCH:

.\cruciblecpp-preprocessor.exe ` --pch-cache .cache\pch ` --pch-cache-stats .cache\pch\stats.json ` -P src\main.cpp -o build\main.i

Il manifest della cache registra il percorso e la versione del compilatore, l'hash del compilatore e quello delle opzioni. I PCH di GCC13/14/15 non producono falsi riscontri tra loro.

Diagnostica

Per impostazione predefinita emette righe di sorgente e caret in stile GCC. Puoi disattivarli o regolarli:

-fdiagnostics-color=auto|always|never -fno-diagnostics-show-caret -fno-diagnostics-show-option -Werror -Wno-error=name --max-errors 20

Supporta #pragma GCC diagnostic push/pop/ignored/warning/error e #pragma GCC system_header. Gli header provenienti da -isystem sopprimono per impostazione predefinita i warning ordinari, mentre -Wsystem-headers può mostrarli di nuovo.

Risoluzione dei problemi

Header della libreria standard non trovati

Il compilatore target non è nel PATH. Usa --gcc per specificarlo, oppure aggiungi la directory bin al PATH. Puoi anche usare -isystem per passarla esplicitamente.

Versione di GCC scelta errata

Usa --gcc-version=13|14|15 per fissare la versione principale, oppure --gcc per puntare a uno specifico g++.exe. Non mescolare un profilo target con gli header di un'altra versione.

La cache PCH segnala “corrupt”

Il PCH non corrisponde al compilatore o alle opzioni correnti, oppure il file è danneggiato. Elimina la voce di cache corrispondente e rigeneralo; in alternativa puoi disattivare del tutto la cache PCH e lasciare che legga i sorgenti degli header.

Output non compilabile con GCC

Assicurati innanzitutto che preprocessing e compilazione usino la stessa versione di GCC e la stessa opzione -std. Poi compila separatamente il “.i generato da CrucibleCpp” per capire se il problema nasce dalla fase di preprocessing.

CrucibleCpp è un preprocessore, non un compilatore. Non si occupa di generazione del codice, ottimizzazione, linking né dell'analisi del formato interno dei PCH binari di GCC.
