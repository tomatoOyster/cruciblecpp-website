バージョン履歴

境界として意味のあるバージョンの節目だけを残しています。中間パッチ版の完全な差分は、GitHub のコミット履歴と Tag で確認できます。

2026-11-17 · latest

V3.0.1 安定版

  • 実プロジェクトでの digraph 処理を修正：GCC -E による <: の表記を維持し、 <:: の出力間隔を正しく処理します。
  • 実プロジェクトの corpus では、前処理とコンパイルの両方が実際に成功することが求められるようになり、「両方とも失敗」を合格と誤判定しなくなりました。
  • nlohmann/json の include レイアウトを修正： nlohmann/json.hpp。
  • ゼロからの clone、ビルド、3 スイートの GCC テスト、実プロジェクトでの検証がすべて成功。
2026-11-17

V3.0.0 ライセンス境界

  • V3.0.0 以降は CC BY-NC 4.0 に切り替わり、V2.9.0 以前は引き続き MIT を使用します。
  • GCC13/14/15 の PCH を完全サポート：バージョン制限を撤廃し、GCC13/14 の PCH magic 検証を修正。
  • PCH cache manifest は、コンパイラのパス、バージョン、実行ファイルのハッシュ、オプション hash を記録します。
  • 3 つの CTest スイートがすべて 65/65 に到達。
2026-11-17

V2.9.0 GCC13/14

  • GCC 13.3 / 14.3 向けの C++11/14/17/20 profile を追加。
  • GCC13/14 の完全な __has_* データを追加。
  • 追加： --gcc-version=13|14|15、--gcc <path> および PATH の自動検出。
  • 3 つの CTest スイートのターゲット選択と、3 コンパイラでの smoke matrix。
2026-11-14

V2.7.0 機能マイルストーン

  • GCC 15.2 の #embed を実装：バイナリ埋め込み、limit、gnu::offset、prefix、suffix、if_empty。
  • 実装： __has_embed、0/1/2 を返します。
  • UCN 識別子の完全サポート：合成、妥当性検査、正規化出力、#/## の表記を保持。
  • C++11 / C++14 / C++17 / C++20 profile。
  • 差分テストシステムと GCC g++.dg/cpp testsuite を統合。
2026-11-12

V2.6.1 診断機能の強化

  • GCC 形式のソース行、caret、include trace。
  • #error/#warning プレフィックス、マクロ再定義 warning、include 欠落の fatal エラー。
  • -fdiagnostics-color、caret/option スイッチ。
  • #pragma GCC diagnostic 状態スタック。

以前のバージョン

v2.5.0、v2.2.0、v2.0.0、v1.0.2 などの Release は維持しています。中間のパッチバージョンは Release ページから削除しましたが、Git Tag はリポジトリ内にすべて残っています。
