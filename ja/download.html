01

システム要件

Windows x64。対象コンパイラは MinGW-w64 UCRT64 GCC 13.3 / 14.3 / 15.2 です。追加のランタイムは不要です。

02

使い方

解凍後はそのまま実行します。 --gcc-version または --gcc で対象コンパイラを選択し、出力した .i を同じ GCC でコンパイルします。

03

ライセンス

V3.0.0 以降は CC BY-NC 4.0 で、表示を伴う非商業利用が可能です。商業利用には別途ライセンスが必要です。

Before you run

まず対象 GCC が PATH にあることを確認

CrucibleCpp は対象コンパイラのプロファイルと include パスを自動的に読み取ります。カスタムディレクトリにインストールした場合は --gcc で指定し、バージョンの混在を避けてください。

cruciblecpp-preprocessor.exe --version cruciblecpp-preprocessor.exe --gcc "D:\path\to\g++.exe" -P src\main.cpp -o build\main.i
